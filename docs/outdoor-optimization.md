# 室外场景优化清单

目标：以《GTA 6》的街区镜头质感为参考，但先把**紫金科创主入口 → 中央连廊**做成能从人眼高度检查的样板。先做准，再做细；暂不重做全园区，也不先换渲染引擎。

## 优先级

| 编号 | 优化项 | 怎么做与怎么验收 |
| --- | --- | --- |
| T0 · 首轮已做 | 实景还原基准 | 用既有航拍对照当前网页，记录可确认轮廓、差异候选和补拍位置；本轮不改模型。详见本页「T0 执行记录」。 |
| T1 · 近景样板 | 主楼首层、雨棚和连廊 | 已在 v14 上细化首层门扇、门槛、雨棚收口和连廊栏板；门洞、坡道和台阶标高仍待地面实拍及实测。 |
| T2 | 玻璃与室内进深 | 区分幕墙、玻璃门和栏板；按朝向做反射，并在能看进去的楼层加入真实的柱、灯和窗帘等轮廓。对比天空、对楼、绿化的反射是否随角度变化，不让石材变镜面。大堂联动见[室内场景路线](indoor-scene-roadmap.md)。 |
| T3 | 路面和建筑接地 | 在既有 8K 地面上叠加近景铺装；补可见路缘、盲道、排水篦子、井盖、车道标线和适量磨损。查草地、铺装、墙脚之间是否浮空或互穿。 |
| T4 | 光照、材质、夜景 | 补柱脚、檐下、绿化根部的接触阴影；区分石材、铝板、玻璃、沥青；夜景补门厅、招牌、路灯和分组亮窗，让光落到地面。对照原始、早晨、傍晚、夜晚。 |
| T5 · 并行验收 | 加载与帧率 | 基线配置引用 84 个不同 GLB（约 90.5 MiB，含两份显式近景资源，不等同首屏预算）；主楼约 17.2 MiB、有 765 个网格图元，不等同实际绘制次数。先量实际请求和绘制开销，再按建筑/街区拆分、合批和做近远景过渡。记录桌面与手机的冷启动、资源量、漫游帧时间及近远景跳变。 |
| T6 | 植被与街道设施 | 按实拍调树冠、树间距、绿篱与地被；补实际有的导视、路灯、车挡、停车位、单车和设施。绿峰中心和永创厂房分别记录，不把一套道具复制到每条街。 |
| T7 | 屋顶、外围楼和沿河 | 优先修主视角能看到的机房、风机组、女儿墙与屋面材质；外围先补正对镜头的白模；沿河先做驳岸、高差和护栏，再考虑水面动态。 |
| T8 | 行人视角与路线 | 保留鸟瞰，加约 1.6 米人眼视角的短路线。验收三个机位：街对面看主楼、走到雨棚下、夜晚回望大堂；同一机位反复比较，不拿高空镜头代替近景验收。 |
| T9 · 后置 | 动态和天气 | 静态样板过关再加少量行人、低速车、近处风动和环境音；雨后优先做局部积水与路面湿润，不把全场变成镜面。 |

## T0 执行记录

基线：2026-11-20，本地场景提交 `cae0c5f`，Chrome 预览 1280 × 720，光照为「原始」。已核对 HTTP 返回的 `project.json` 与工作区一致。实拍来自此前用于建模的约 30 秒航拍，以下时间是视频内时间；原片和临时截帧不随仓库发布。

| 对照点 | 实拍与预览 | 首轮结论 |
| --- | --- | --- |
| 紫金科创主楼正面 | 航拍 `00:18` ↔ [主入口](http://127.0.0.1:8785/?view=arrival) | 双楼圆角轮廓、向中间退台、连桥和中庭洞口已有对应，先保留总体外形。实拍的屋顶机房、成组设备更清晰，玻璃的反射和窗内明暗变化更丰富；当前正面机位屋顶被遮较多，用侧向航拍继续核对，不凭这一张判定设备缺失。 |
| 退台、屋顶与中央连廊 | 航拍 `00:08`、`00:27` ↔ [空中绿轴](http://127.0.0.1:8785/?view=campus-video)、[中央连廊](http://127.0.0.1:8785/?view=bridge) | 退台、屋顶设备、连桥与三叶亭均有对应。实拍屋面能分清设备串列、檐边和铺装分区；当前近景连桥能看到栏板，但入口门洞、雨棚底面和地面细节只适合列为待测项，航拍不能给出准确尺寸。 |
| 绿峰中心 | 航拍 `00:18` 中的背景 ↔ [绿峰中心](http://127.0.0.1:8785/?view=lvfeng) | 双塔与裙房的整体关系可作方向性核对，正立面有遮挡；暂不据此更改层高、幕墙分格或裙房入口。补正立面全高和斜侧街景各一张。 |
| 永创智能后排厂房 / 路口 | [厂房路口](http://127.0.0.1:8785/?view=factory-junction) | 已记录现状渲染；本次航拍没有足以确认身份、尺度和立面分格的清晰画面。补能同框看到后排厂房外角和路口的广角，再拍装卸口和沿街设施。保持现有落位。 |

**这不是测绘验收。** 现有航拍没有相机标定，网页预设是相近方位，不是严格同机位；不能用像素差直接反推高度或路宽，也不能从不同曝光的画面推算玻璃色值。建筑改动前，优先用两侧楼角、连桥桥台、屋顶女儿墙四类锚点配准；门洞、台阶、路缘用有尺寸的现场资料复核。

### 下一轮最少补拍

1. **街对面正视主楼**：同框包含双楼外角、雨棚、门洞和人行道路缘。记录拍摄站位、镜头倍率与大致相机高度。
2. **沿入口斜拍和雨棚下回拍**：同框看到门槛、立柱、雨棚底和连桥接点；实测门洞净宽、台阶高差、相邻柱距。再补一张同站位夜景。
3. **第二批补拍**：绿峰中心正面和斜侧、永创后排厂房与路口。不阻塞主楼首层样板，但未拍到的位置继续标记未验证。

本地打开方式见 [README](../README.md)。后续迭代应复用表中 `view` 链接、相同画幅和光照；需要新增严格同机位对照时，另记相机位置、朝向、视场角与对应实拍。
