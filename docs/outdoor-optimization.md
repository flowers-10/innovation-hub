# 室外场景优化清单

目标：以《GTA 6》的街区镜头质感为参考，但先把**紫金科创主入口 → 中央连廊**做成能从人眼高度检查的样板。先做准，再做细；暂不重做全园区，也不先换渲染引擎。

## T0 执行记录

基线：2026-11-20，本地场景提交 `cae0c5f`，Chrome 预览 1280 × 720，光照为「原始」。已核对 HTTP 返回的 `project.json` 与工作区一致。实拍来自此前用于建模的约 30 秒航拍，以下时间是视频内时间；原片和临时截帧不随仓库发布。

| 对照点 | 实拍与预览 | 首轮结论 |
| --- | --- | --- |

| 退台、屋顶与中央连廊 | 航拍 `00:08`、`00:27` ↔ [空中绿轴](http://127.0.0.1:8785/?view=campus-video)、[中央连廊](http://127.0.0.1:8785/?view=bridge) | 退台、屋顶设备、连桥与三叶亭均有对应。实拍屋面能分清设备串列、檐边和铺装分区；当前近景连桥能看到栏板，但入口门洞、雨棚底面和地面细节只适合列为待测项，航拍不能给出准确尺寸。 |
| 绿峰中心 | 航拍 `00:18` 中的背景 ↔ [绿峰中心](http://127.0.0.1:8785/?view=lvfeng) | 双塔与裙房的整体关系可作方向性核对，正立面有遮挡；暂不据此更改层高、幕墙分格或裙房入口。补正立面全高和斜侧街景各一张。 |
| 永创智能后排厂房 / 路口 | [厂房路口](http://127.0.0.1:8785/?view=factory-junction) | 已记录现状渲染；本次航拍没有足以确认身份、尺度和立面分格的清晰画面。补能同框看到后排厂房外角和路口的广角，再拍装卸口和沿街设施。保持现有落位。 |

**这不是测绘验收。** 现有航拍没有相机标定，网页预设是相近方位，不是严格同机位；不能用像素差直接反推高度或路宽，也不能从不同曝光的画面推算玻璃色值。建筑改动前，优先用两侧楼角、连桥桥台、屋顶女儿墙四类锚点配准；门洞、台阶、路缘用有尺寸的现场资料复核。

### 下一轮最少补拍

1. **街对面正视主楼**：同框包含双楼外角、雨棚、门洞和人行道路缘。记录拍摄站位、镜头倍率与大致相机高度。
2. **沿入口斜拍和雨棚下回拍**：同框看到门槛、立柱、雨棚底和连桥接点；实测门洞净宽、台阶高差、相邻柱距。再补一张同站位夜景。
3. **第二批补拍**：绿峰中心正面和斜侧、永创后排厂房与路口。不阻塞主楼首层样板，但未拍到的位置继续标记未验证。

本地打开方式见 [README](../README.md)。后续迭代应复用表中 `view` 链接、相同画幅和光照；需要新增严格同机位对照时，另记相机位置、朝向、视场角与对应实拍。

## T1 执行记录

- 紫金科创主楼以可编辑的「双侧连续挡雨板延伸 · 无树 v14」为基底。保留建筑落位、双侧延伸挡雨板和中央拱面本体；原银边与板缝重新贴合 v14 的拱面。
- 沿用现有门框与门槛位置，补充双扇门、门框侧边、拉手固定件、门槛防滑条及前露台栏板固定座。门扇为闭合近似，不代表实测尺寸，也不包含可进入的室内。
- [雨棚下人眼视角](http://127.0.0.1:8785/?view=t1-pedestrian) · [门槛人眼视角](http://127.0.0.1:8785/?view=t1-threshold)。两处为检查用直达机位，不改原有菜单与飞行路线。
- 新 GLB 约 26 MiB，约 51.5 万个三角面；比旧网页模型约大 8.8 MiB。已在 Chrome 核对新资源请求、主入口和连廊，并切换早晨、傍晚和夜晚。手机帧率仍待实测。

## T2 执行记录

- 在 v14-T1 基础上导出 v14-T2 GLB，保留雨棚、门框、门槛和现有机位。两处靠连廊的入口改用透射玻璃，玻璃后有可见的柱、吊顶、暖色顶灯和陈设轮廓；仅作室外观察的近似样板，不是实测大堂，也不能行走进入。
- 幕墙保留三种反射和粗糙度，栏板与入口玻璃分别处理；沿用两翼与连廊的局部反射探针，夜间降低反射强度，移除对不透明楼层带的探针反射覆盖。

## T4 执行记录

- 沿用 v14-T3 入口，在 v14 的拱形雨棚底面加六盏[筒灯](../assets/models/campus/zijin-entrance-lights-t4.glb)。深色金属外圈与漫射灯面分开，暖光有范围限制，主要落在门槛、铺装和篦子；不提高全场曝光，不新增实时阴影贴图。灯位和亮度为预览近似，不是夜间实测。
- 原始与早晨关闭，傍晚约为夜晚的 38%，夜晚全亮；复用现有昼夜过渡和减少动态效果设置。可用 [夜间入口](http://127.0.0.1:8785/?view=t3-forecourt&time=night) 或 [夜间门槛](http://127.0.0.1:8785/?view=t1-threshold&time=night) 直接检查，默认入口不变。

## T5 执行记录

- [v14-T5 网页模型](../assets/models/campus/zijin-kechuang-v14-t5.glb)把主楼小网格按材质、空间和原反射探针分组合批。保留透明及透射玻璃的独立网格、入口和室内细节；不减面。主楼仍为 515,185 个三角面，图元从 2,422 降至 475。此文件用于网页，后续建模仍从可编辑的 v14-T4 源文件开始。
- 同机 Chrome、关闭 HTTP 缓存、同机位对照：主楼 GLB **26.15 → 22.26 MiB**；菜单可用前已完成的资源响应体总量 **113.38 → 109.50 MiB**。渲染统计含附加渲染通道，主入口调用 **6,321 → 2,427**、连廊 **4,119 → 1,981**、夜间入口 **3,997 → 1,963**。从主入口、鸟瞰、连廊、门槛、沿河以及夜间入口检查反射、透射和雨棚灯。
- 1440 × 900 漫游的帧间隔中位数在两组测试中分别为 33.2 → 16.8 ms 与 16.7 → 16.7 ms，P95 都约 33.4 ms；不能据此承诺帧率翻倍。390 像素为桌面窄屏模拟而非手机实机，局域加载耗时也未稳定改善。
