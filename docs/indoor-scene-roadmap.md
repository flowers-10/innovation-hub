# 室内场景：大堂样板与制作路线

**推荐：实测 / CAD 定尺度，Blender 建空间，实拍做材质；同一个大堂另做一次高斯溅射试扫。** 主版本继续用 GLB，保留未来做进门、碰撞、昼夜切换的空间。试扫先独立查看，不把整栋楼或现有网页绑到某个扫描平台。

## 怎么选

| 方式 | 最适合 | 注意事项 |
| --- | --- | --- |
| 手工建模 + 实拍材质 | 大堂、入口、与室外连续的连廊；需要行走、开门或换灯的空间 | 门洞、楼层、台阶和玻璃要实测；用可见的室内进深补真实感，不必把所有房间都建出来。 |
| 高斯溅射（3DGS） | 有复杂陈设、短期不改造的实景展厅；快速验证现场观感 | 普通扫描不自带可编辑家具、物理碰撞或可重打的灯光；玻璃、白墙、背光和拍摄盲区必须实测。先确认能导出 `Splat PLY` 或查看器支持的格式，不假设现有 GLB 加载器能直接读取。 |
| 摄影测量 → 网格 | 独特展品、雕塑、纹理丰富的装饰构件 | 清理网格、减面和烘焙后再并入 GLB；标准家具直接建模，玻璃和镜面优先手工做。 |
| CAD / 激光测距 / LiDAR | 获取墙、门、柱、层高和地面高差，给模型定尺度 | 点云或参数化房间是测量参考，不是最终材质。门净宽、门槛和连廊标高用实测复核。 |
| 360° 全景 | 可点看但不必连续走进去的会议室、办公区 | 可以用热点切换站位，不适合作为自由行走的替代。 |

Luma AI、Scaniverse、Polycam 都只作为候选工具；是否采用以实测的导出格式、独立部署、数据处理条款和手机表现为准。开始扫之前先拿一小段已获授权的素材做“导出 → 独立打开 → 手机试播”，不要只在平台自己的查看器里验收。

## I0 · 只做紫金科创大堂的第一段

范围：**门外 → 玻璃门 → 前台 → 回头看室外**。首版不做整层办公、不做电梯和全楼室内导航。

- [ ] **采集尺度**：拿大堂平面图或手绘带尺寸草图；记录门洞净宽、净高、室内外高差、柱距、吊顶高度、玻璃分格和前台位置。选择门槛与一个柱角作为内外对齐基准。
- [ ] **拍实景**：拍门外正面、门外斜视、门内背看、前台全景；材质另拍地砖、墙面、玻璃边框、吊顶和标识。扫 3DGS 时绕行，覆盖门内外与物体背面；尽量避开来往人员和曝光突变。夜景另拍一组。
- [ ] **做可编辑样板**：先搭墙、地、顶、柱、门和台阶，验证尺寸与走位；再做门厅灯、前台、材质和最低限度的家具。玻璃在门内与门外各查一遍。
- [ ] **接入园区**：从入口触发，按需加载；保留室外曝光、朝向与位置的连续性。显示模型和碰撞体分开；退出时回到原入口附近。网页资源走 `assets/models/`，模型按版本命名。
- [ ] **做同场试扫**：用同一个大堂导出一份 3DGS，在桌面和手机上对照 GLB。记录制作工时、补洞和清理时间、下载量、进入耗时、走动时卡顿，以及门框和玻璃处的画面缺陷。
- [ ] **处理隐私**：得到拍摄和公开许可；避开或清除屏幕、工牌、人脸、车牌及不公开的平面图。原图、原始扫描和临时测试数据不进公开仓库。

## 验收与扩展

- **四个机位**：门外斜向前台、站在门槛处、门内回看室外、夜晚从室外看门厅。固定机位做实拍与渲染对比，记录误差，不拿效果图当测量依据。
- **可走**：门口和台阶不穿模、不被无形障碍卡住；碰撞边界和实际门洞一致；进出不会明显跳光或跳镜头；夜间门厅光落到地面。
- **可用**：用同一台桌面和目标手机测试，分开记录冷启动、室内加载和漫游稳定性；不能为了一个房间拖慢园区首页。
- **扩展顺序**：大堂通过 → 可见连廊和一间典型会议室 → 再决定展厅用 GLB、溅射或全景。只看、不走的空间不必都做成自由漫游。

室外接口与制作优先级见[室外优化清单](outdoor-optimization.md)。
